# Easy AI Chat (amateur)

You do **not** need pro terms. Open **AI Chat** and either:

1. **Tap a chip**, or  
2. **Type a short sentence**

## Chips

| Chip | What it does |
|------|----------------|
| Use cam in Zoom | Steps to put Endless Cam into Zoom |
| Use cam in Teams | Same for Microsoft Teams |
| Use cam in Discord | Same for Discord |
| Face swap live | Real-time face swap path |
| Face swap photo | Still image swap + export |
| Go live on Twitch | RTMP / NVENC live |
| Setup OBS | Manual OBS integration |
| WhatsApp photo swap | Still export for chat/status |

## Type like this

- `use my cam in Zoom`
- `face swap live`
- `face swap photo`
- `go live on Twitch`
- `setup OBS`
- `WhatsApp still face swap`
- `Telegram photo`
- `Snapchat still export`

## Before any call app works

Run once in a terminal:

```bash
python bridge/endless_engine.py
```

Then follow the chat steps to pick that camera in Zoom/Teams/etc.
